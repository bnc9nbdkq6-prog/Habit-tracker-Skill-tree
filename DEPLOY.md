# Richting

Persoonlijke Nederlandstalige skilltree. Next.js, React, uitsluitend lokale browseropslag. Geen accounts, database of synchronisatie.

`npm install`, `npm run dev`; productie: `npm run build`, `npm start`.

Publiceer via het bestaande Vercel-project gekoppeld aan deze GitHub-repository. Er zijn geen omgevingsvariabelen nodig. Oude Supabase-variabelen mogen uit Vercel worden verwijderd.

Gegevens en versiegeschiedenis worden in localStorage opgeslagen, per browser en domein. Exporteer regelmatig een JSON-back-up via Bewaren. Browsergegevens wissen verwijdert ook deze gegevens. Verwijderde takken zijn via Geschiedenis te herstellen.

Hiërarchie: tienjaarsvisie > jaardoel > maanddoel > project > weekmijlpaal. Een project mag ook direct bij een jaar- of tienjaarsdoel horen, zodat meerjarige projecten mogelijk blijven. Ieder onderdeel behalve de tienjaarsvisie heeft een ouder. Afronden van een tak rondt de onderliggende onderdelen af; heropenen opent de bovenliggende onderdelen opnieuw. Voortgang telt voltooide eindpunten, niet bestede uren.
